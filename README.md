**Violet Lite**는 오리지널 Violet을 현대 모바일 환경에 최적화하여 불필요한 기능들을 과감히 덜어내고 성능과 편의성을 극대화한 **경량화 버전**입니다. (기존 Violet과 충돌 없이 동시 설치 가능)

## 핵심 차이점

| 구분               | 공식 Violet                            | Violet Lite                                           |
| :----------------- | :------------------------------------- | :---------------------------------------------------- |
| **초기 실행**      | 30MB+ 대용량 DB 다운로드 대기          | **다운로드 대기 0초, 즉시 스트리밍 시작**             |
| **코어 엔진**      | 순수 Dart 연산                         | **Rust 네이티브 FFI 엔진**                            |
| **대사 검색 부활** | PC 환경 전용 (수 GB 데이터 필요)       | **모바일 경량 대사 검색 (Latest 2026/7/5)**           |
| **신작 탐색**      | 미지원                                 | **히토미 독점 신작 0ms 단독 필터**                    |
| **저장공간 관리**  | 이미지·썸네일 무한 누적으로 용량 잠식  | **이미지 캐시 100MB 상한 자동 제어 (LRU 스마트 정리)**|
| **열람 진행도**    | 30일 경과 시 진행도 및 완독 초기화     | **열람 진행도 및 완독(흑백) 표시 영구 보존**          |
| **코드베이스**     | 약 12만 줄의 방대한 레거시 구조        | **약 7만 줄 (-40%)로 대폭 슬림화 & 메모리 누수 해결** |

## v2 대규모 개편 상세

### 1. Rust 네이티브 코어 엔진 탑재 (FFI 가속)

- **3,000만 건 한국어 대사 온디바이스 검색**:
  - PC에서만 가능하던 대사 검색을 모바일용 경량 코퍼스(`.fscm.7z`)로 압축 구축하여 기기 내에서 로컬로 즉시 검색합니다.
- **영타 오타 자동 복원**:
  - 한영 전환을 잊고 영타(예: `rkdmf` $\rightarrow$ `가을`, `dkssud` $\rightarrow$ `안녕`)로 입력해도 한글 2벌식 자모 분해 및 오토마타 재조합 엔진이 0ms 만에 완성형 한글로 즉시 자동 변환·복원합니다.
  - 대사 검색뿐만 아니라 태그 및 작품명 검색 전반에 적용되어 오타로 인한 검색 실패를 방지합니다.
- **Nozomi 바이너리 파서 & 초고속 다중 교집합**:
  - 4바이트 Big-Endian 네트워크 바이너리 파싱을 Rust로 처리하여 대량 태그 검색 시 수만 건의 교집합 연산을 0ms 만에 산출합니다.
- **지각적 차이 해시(dHash) 기반 판본 그룹화**:
  - 표지 이미지의 시각적 지각 해시를 Rust SIMD 연산으로 비교하여, 제목이 오등록되거나 다른 언어로 출간된 동일 작품을 100% 정확하게 하나로 묶어줍니다.

### 2. 하이브리드 스트림

- **초기 DB 다운로드 완전 폐지**:
  - 앱을 처음 켤 때 수십 MB의 인덱스 DB 다운로드를 기다릴 필요 없이, 실행 즉시 메인 화면이 열립니다.
- **Hitomi Nozomi + E-Hentai 하이브리드 파이프라인**:
  - 최신 웹 인덱스를 백그라운드에서 병렬 스트리밍 수집하여 항상 최신 작품 목록을 지체 없이 표시합니다.

### 3. 이미지 디스크 캐시 최적화 및 스마트 용량 관리 (`AppCacheManager`)

- **이미지 디스크 캐시 100MB 상한(Budget) 자동 제어**:
  - 만화를 열람하거나 목록을 탐색할 때마다 기기 저장공간에 무제한으로 쌓이던 이미지 디스크 캐시 문제를 근본적으로 해결했습니다.
  - **뷰어 본문 이미지 캐시 (`cacheimage`)**: 55MB 초과 시 LRU(최근 사용 순) 기반 자동 정리 및 6시간 경과 파일 자동 파기.
  - **목록 썸네일 캐시 (`libCachedImageData`)**: 45MB 초과 시 또는 이틀 경과 시 자동 청소.
  - 아무리 많은 만화를 감상해도 기기 용량을 수백 MB\~수 GB씩 잠식하지 않고 최대 100MB 이내로 항상 쾌적하게 유지합니다.
- **백그라운드 자동 청소 & 원클릭 캐시 비우기**:
  - 뷰어를 닫거나 앱을 실행할 때마다 백그라운드에서 캐시 상한(`enforceBudget`)을 자동 집행하여 번거로운 수동 정리가 필요 없습니다.
  - 설정 화면에서 축적된 썸네일, 이미지, 웹뷰 캐시 용량을 실시간 확인하고 원클릭으로 완전히 비울 수 있습니다.
- **작품 상세 팝업(바텀시트) 25배 가속 (\~1,650ms $\rightarrow$ \~60ms)**:
  - `HitomiImageResolver` 단일 패스 생성기 및 `gg.js`·`galleryinfo.js` 인메모리 캐시를 적용하여 중복 네트워크 요청을 없애고 배터리와 데이터 낭비를 최소화했습니다.

### 4. 코드베이스 -40% 다이어트 및 무결성 확보

- **약 5만 줄의 레거시 코드 제거**:
  - 모바일 환경에서 쓰이지 않던 구형 C# 도구(`hsync`), 레거시 다운로드 모듈, 불안정한 실험 기능들을 과감히 정리하여 앱 용량과 빌드 속도를 대폭 줄였습니다.
- **치명적 리소스/메모리 누수 차단**:
  - HTTP 404 스크립트 오염 방어, 뷰어 메모리 누수 방지, 프로세스 라이프사이클 안정화를 완벽히 마쳤습니다.

### 5. 모바일 중심의 스마트 편의 기능

- **Hitomi 독점 신작 필터**: E-Hentai에 없는 히토미 단독 신작만 0ms 만에 골라보는 토글 필터를 제공합니다.
- **마지막 탐색 위치 영구 기억**: 앱을 종료했다가 다시 켜도 보던 스크롤 위치(`[📍 마지막 본 위치]`)로 즉시 이동할 수 있습니다.
- **열람 진행도 영구 보존**: 30일 만료 타이머를 완전히 폐지하여 한 번 읽은 작품의 진행도와 완독 표시가 영구히 보존됩니다.
- **태그 즐겨찾기**: 검색 화면 상단에서 자주 찾는 태그 및 작가를 원클릭으로 빠르게 탐색합니다.

## 주요 기능

- **즉시 시작**: 초기 대용량 데이터베이스 다운로드 없이 바로 실행됩니다.
- **Hitomi 단독 필터**: 상단 눈동자 아이콘으로 히토미에만 올라온 순수 신작만 선별합니다.
- **한국어 대사 검색**: 기기 내 Rust 엔진으로 약 3,000만 건의 한국어 만화 대사를 초고속 검색합니다 (영타 오타 자동 복원 지원).
- **스마트 캐시 관리**: 무한정 쌓이던 이미지·썸네일 캐시를 100MB 상한선 내에서 LRU로 자동 제어하여 기기 저장공간을 보호합니다.
- **스마트 이어보기**: 스크롤 위치 및 마지막으로 본 작품(`[📍 마지막 본 위치]`)을 기억하여 앱 재실행 시에도 바로 복원합니다.
- **태그 즐겨찾기**: 검색창 상단 팝업을 통해 자주 찾는 태그/작가를 원클릭으로 검색합니다.
- **기간 검색**: `date:2024`, `date>=2024`, `date:2020\~2023` 등 직관적인 날짜 필터링을 지원합니다.
